
1. Admin Adds a Plant
Open admin.html in your browser.

Fill in the form (e.g., Name: Aloe Vera, Category: Medicinal, Price: 120, Stock: 15).

Submit → backend saves it in MongoDB (plants collection).

You should see the new plant appear in the admin list.

2. Catalog Shows Plant
Open catalog.html.

The new plant (Aloe Vera) should now appear alongside Rose, Tulip, Jasmine, etc.

This confirms frontend → backend → database connection is working.

3. Customer Adds to Cart
Click Add to Cart on Aloe Vera.

A popup alert confirms it’s added.

Cart data is stored in localStorage.

4. Cart Page Displays Items
Open cart.html.

You should see Aloe Vera listed with its price.

Total is calculated automatically.

5. Checkout
Click Checkout.

The cart data is sent to backend (/orders route).

Backend saves it in MongoDB (orders collection).

You’ll see an alert: “Order placed successfully!”

Cart clears from localStorage.



Admin can manage plants.

Customers can browse, add to cart, and checkout.

Orders are saved in the database.
